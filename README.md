## 2. Platform Overview

MedPredict AI is an end-to-end, modular, production-style medical data analytics and multi-disease risk prediction platform. It bridges data science, machine learning, and full-stack software engineering to provide:
- **10 Modular Disease Risk Engines**: Diabetes, Heart Disease, Liver Disease, Chronic Kidney Disease, Breast Cancer, Stroke, Hypertension, Anemia, Thyroid Disease, and Parkinson's Disease.
- **Dataset Management & Profiling**: Automated schema validation, data quality scoring, duplicate and outlier detection, and Parquet/CSV/XLSX ingestion.
- **Model Training Workspace & Registry**: Training with cross-validation, automated metric calculation (Accuracy, Precision, Recall, F1, ROC-AUC, PR-AUC), artifact checksum hashing, and version control.
- **Explainable AI (XAI)**: SHAP-based local and global feature attribution ensuring clinical interpretability without establishing false causality.
- **Role-Based Workflows**: Dedicated interfaces and access policies for **Patient**, **Doctor**, **Data Scientist**, **Admin**, and **Auditor**.
- **Observability & Audit Trail**: Structured event logging, security monitoring, `/health` and `/ready` probes.

## 5. Getting Started & Installation

### Prerequisites
- Python 3.12 or 3.13
- Node.js 20+ and NPM
- Docker and Docker Compose (recommended)
- Git

### 1. Clone & Set Up Environment
```bash
git clone https://github.com/medpredict-ai/medpredict-ai.git
cd medpredict-ai
cp .env.example .env
```

### 2. Backend Setup
```bash
# Create and activate virtual environment
python -m venv venv
# On Windows:
.\venv\Scripts\activate
# On Linux/macOS:
# source venv/bin/activate

# Install dependencies
pip install -r backend/requirements.txt

# Run migrations and start API server
uvicorn backend.app.main:app --reload --host 0.0.0.0 --port 8000
```
Interactive OpenAPI documentation will be accessible at: `http://localhost:8000/docs`

### 3. Frontend Setup
```bash
cd frontend
npm.cmd install    # Windows (or npm install on Linux/macOS)
npm.cmd run dev
```
Frontend web interface will be accessible at: `http://localhost:5173`

### 4. Running with Docker Compose
```bash
docker-compose up -d --build
```
This launches PostgreSQL (5432), Redis (6379), FastAPI Backend (8000), and React Frontend (5173).
